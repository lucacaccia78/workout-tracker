WORKOUT TRACKER PWA — ISTRUZIONI RAPIDE

1. Pubblica tutti i file di questa cartella su un hosting HTTPS.
   Opzione semplice: GitHub Pages.

2. GitHub Pages:
   - crea un repository nuovo su GitHub
   - carica tutti i file contenuti qui
   - Settings > Pages
   - Source: Deploy from a branch
   - Branch: main / root
   - salva e attendi il link pubblico

3. Su iPhone:
   - apri il link in Safari
   - Condividi
   - Aggiungi alla schermata Home
   - apri poi sempre dall'icona Workout

I dati degli allenamenti vengono salvati localmente sul dispositivo/browser.
Usa il pulsante Backup per esportare periodicamente i dati.
